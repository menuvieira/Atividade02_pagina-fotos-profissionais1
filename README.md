# 📸 Página de Fotos Profissionais — Front-End

Projeto desenvolvido como atividade prática para a disciplina de **Front-End** do curso superior de **Análise e Desenvolvimento de Sistemas (ADS)** da **Faculdade Senac Pernambuco**.

O objetivo do projeto é replicar com fidelidade a estrutura visual e os componentes de um layout de estúdio de fotografia profissional, aplicando boas práticas de desenvolvimento web.

## 🚀 Tecnologias Utilizadas

- **HTML5:** Estruturação semântica da página (`<header>`, `<nav>`, `<section>`, `<footer>`).
- **CSS3:** Estilização, layout responsivo e alinhamentos modernos.
  - **Flexbox:** Alinhamento do menu de navegação, cards e itens do rodapé.
  - **CSS Grid Layout:** Organização da grade de serviços e da galeria de fotos.
- **Font Awesome:** Ícones vetoriais para redes sociais.

---

## 📌 Funcionalidades e Estrutura

- **Cabeçalho Fixo (Sticky Header):** Barra de navegação com links diretos para as seções da página.
- **Seção Hero (Destaque):** Banner principal com imagem de fundo, texto explicativo e botão de chamada de ação.
- **Seção Sobre:** Bloco institucional centralizado e estilizado com a paleta principal do projeto.
- **Seção Serviços:** Exibição dos serviços prestados em *cards* informativos com ícones customizados.
- **Galeria de Fotos:** Grade de imagens sem espaçamento interno, ajustada à largura da tela.
- **Rodapé (Footer):** Informações de contato local (Recife - PE), links de e-mail/telefone, redes sociais e navegação para o topo.
